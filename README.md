# MovieHub 🎬

React-приложение для поиска фильмов и формирования списка «Посмотреть позже».

## 🔗 GitHub

https://github.com/NikPonzep/MovieHubTs

## 🚀 Технологии

* React
* TypeScript
* Vite
* React Router
* Axios
* React Hook Form
* Zod
* TanStack Query
* React Icons
* Lucide React
* Motion
* CSS Modules

## 📌 Возможности

* просмотр списка фильмов
* поиск фильмов
* просмотр рейтинга и жанров
* добавление фильмов в список «Посмотреть позже»
* удаление фильмов из списка
* отдельная страница со списком фильмов
* анимации интерфейса
* адаптивная верстка

## 🛠 Установка

Клонировать репозиторий:

```bash
git clone https://github.com/USERNAME/MovieHubTs.git
```

Перейти в папку:

```bash
cd MovieHubTs
```

Установить зависимости:

```bash
npm install
```

Запустить проект:

```bash
npm run dev
```

## 📁 Основные технологии

Данные о фильмах получаются через API.

Проект создан в учебных целях для изучения React и TypeScript.
